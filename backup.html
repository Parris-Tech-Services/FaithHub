    Privacy and recovery limits

    Browser storage and JSON backups are unencrypted. Someone with access to your device, browser profile or backup file might read them. Saving a file doesn't confirm the download is safely stored, so check your Downloads folder and keep a second secure copy if needed.

    Restore does not delete entries absent from a backup. It makes all selected writes only after validation and attempts to roll them back if any write fails; a device or browser failure can still prevent recovery. Reload open FaithHub tabs after restoring.
